📸 How to Add Your Own Photos

  1. Prepare your photos: rename them descriptively (e.g. misty-morning.jpg)
  2. Convert to WebP using squoosh.app (free, browser-based) — WebP is smaller and faster
  3. Copy the WebP files into the assets/images/ subfolders on your computer
  4. In the image fields above, replace the https://picsum.photos/... URLs with your local path like assets/images/hero/hero-home.webp
  5. Click Save Image Changes, then go to Export Config tab and download the new config.js
  6. Replace the file on your Netlify site (push to GitHub or drag-drop in Netlify dashboard)

Export config.js

This generates a new config.js file with all your saved settings. Download it and replace the existing assets/js/config.js file in your project — then push to GitHub to update your live site.

How to Deploy Changes

  1. Click Generate config.js above and download it
  2. Find the assets/js/config.js file in your project folder on your computer
  3. Replace it with the downloaded file
  4. Open Terminal and run: git add assets/js/config.js && git commit -m "Update site config" && git push
  5. Netlify will automatically rebuild and deploy your site in ~30 seconds

Clear All Overrides

This removes all saved changes from this browser and reverts the site preview back to the current config.js file values. Use this if you've already exported and deployed your config.
